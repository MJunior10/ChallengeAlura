# 📊 Análise de Vendas e Avaliações de Lojas

Este projeto realiza uma análise exploratória de dados de quatro lojas com o objetivo de entender padrões de vendas, avaliações dos clientes, categorias de produtos, custo de frete e outros indicadores relevantes para o negócio.

## 🧠 Objetivos

- Calcular o faturamento total de cada loja.
- Identificar as categorias mais populares em vendas.
- Avaliar a média das avaliações dos clientes por loja.
- Determinar os produtos mais vendidos e menos vendidos.
- Calcular o frete médio praticado em cada loja.
- Visualizar os dados de forma clara e informativa com gráficos.

## 🗂️ Conjunto de Dados

Os dados foram obtidos dos seguintes arquivos CSV:

- `loja_1.csv`
- `loja_2.csv`
- `loja_3.csv`
- `loja_4.csv`

Fonte: [Repositório Challenge Data Science - Alura](https://github.com/alura-es-cursos/challenge1-data-science)

- Python 3.x
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📈 Análises Realizadas

- **Faturamento por loja:** soma dos preços dos produtos vendidos.
- **Distribuição por categoria:** contagem dos produtos por categoria para identificar os mais populares.
- **Média de avaliação dos clientes:** cálculo por loja para medir a satisfação.
- **Frete médio:** cálculo do custo médio de entrega por loja.
- **Produtos mais e menos vendidos:** identificação com base na frequência de vendas.
- **Visualizações:** gráficos de barras, linhas e pizza para ilustrar os resultados de forma clara.

## 🔍 Insights Relevantes

- A loja com maior faturamento também possui o maior frete médio.
- Apesar disso, essa mesma loja tem a menor média de avaliação dos clientes.
- Isso sugere que o custo do frete pode estar impactando negativamente a experiência do consumidor, mesmo com alto volume de vendas.
